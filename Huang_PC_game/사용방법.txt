1. 지금 Windows 내장 카메라로 시험
ZIP을 모두 추출하고 HUANG 폴더에서 start_webcam.bat을 두 번 클릭합니다.
이 파일은 먼저 기존 Documents\robot_hand 가상환경의 python.exe를 사용합니다.
다른 경로에 있는 경우 기존에 MediaPipe가 작동했던 가상환경을 활성화한 PowerShell에서
HUANG 폴더로 이동해 python huang_live.py 를 실행하세요.
새 환경이 필요한 경우 Windows 64비트 Python 3.11에서 다음을 실행합니다.
py -3.11 -m venv .venv
.\.venv\Scripts\python -m pip install mediapipe==0.10.21
.\.venv\Scripts\python huang_live.py
카메라를 여는 데 실패하면 카메라를 쓰는 다른 앱을 닫고 Windows의 데스크톱 앱 카메라 액세스 권한을 확인합니다.
다른 카메라 번호를 시험하려면 PowerShell에서 .\start_webcam.bat --camera 1 을 실행합니다.

2. 게임 조작
창을 클릭하고 손을 편 채 O, 진행 표시가 끝난 다음 주먹을 쥔 채 C를 누릅니다.
Play Game을 클릭하고 손을 보여 준 상태에서 스페이스바를 누릅니다.
3, 2, 1 뒤 SHOW!에 맞춰 한 손으로 패를 내고 잠시 유지합니다.
가위는 검지와 중지를 펴세요. 화면에는 사용자 패, HUANG 패, 승패가 뜹니다.
다시 Space로 재경기, Motion Track으로 복귀, F로 전체화면 전환, Esc로 종료합니다.
보정 범위가 작다는 안내가 나오면 다시 O/C를 실행합니다.

3. 나중에 D3-G 연결 (기존 ~/robot_hand 및 .venv, camera.py가 있는 보드)
PC 웹캠 앱을 Esc로 종료합니다. Windows PowerShell에서 압축을 푼 HUANG 폴더의 상위 폴더로 이동합니다.
보드IP는 그날 PuTTY로 접속한 실제 IP로 바꿉니다. HUANG 폴더 전체가 복사됩니다.
scp -r HUANG topst@보드IP:~/robot_hand/
cd HUANG
python pc_game.py 보드IP
SSH 로그인 후 이 PowerShell 창은 계속 열어 둡니다.
Python이 py로 설치되어 있으면 py -3 pc_game.py 보드IP 도 됩니다.
이 프로그램은 표준 라이브러리와 Windows OpenSSH 클라이언트를 사용하고 SSH 터널을 통해 게임을 처리합니다.

D3-G에서 기존 영상 앱을 Esc로 닫고 PuTTY에서 다음 한 줄을 실행합니다.
cd ~/robot_hand && PYTHONPATH="$PWD" DISPLAY=:1 .venv/bin/python HUANG/huang_live.py --board
기본 화면과 클릭 위치는 TigerVNC에 유지됩니다. O/C 보정 후 Play Game → Space로 시작합니다.
Motion Track은 보드에서 처리합니다. 게임 모드에서는 보드가 손가락 수치와 키 입력을 보내고,
Windows가 타이밍, 무작위 패, 판정과 로봇 목표값을 계산해 돌려줍니다.
연결이 끊어지면 Waiting for PC가 표시되고 진행 중 판은 취소됩니다. PC 호스트를 다시 연결한 뒤 Space로 시작합니다.
두 방식 모두 위 명령만으로는 모터를 구동하지 않습니다.
